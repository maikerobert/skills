# Contributing

Suggestions are welcome, especially from people who used these skills on real projects.

- **False positive or false negative in a check:** open an issue with the snippet or URL (never real secrets) and what you expected to happen.
- **New AI writing pattern for Humanizer PT-BR:** send a before and after example in Portuguese. Patterns that only show up in isolation rarely make it in, because they also occur in human writing.
- **Pull requests:** one change per PR, describing the problem it solves. Scripts must pass ShellCheck, Python must compile, and the repository must pass its own portability check. All of this runs automatically on GitHub Actions.

Code, identifiers, comments and commit messages are in English. Text in Portuguese follows the Humanizer PT-BR rules: no em dashes, no "não é X, é Y" and no chopped sentences.
