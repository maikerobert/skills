# Landing Page Standard

Landing pages that convert, worked in the order that matters: the buyer and their awareness stage, the promise, the proof, the objections, the calls to action, pricing, the signup flow, the visual, speed and measurement. Builds a new page with a gate on the message before any design, or reviews an existing one with ranked findings.

## Why

Most landing page advice starts at the end of the chain: button color, a new font, a prettier hero. Conversion is decided earlier: who the visitor is, what they already know, what the page promises and whether the proof is as strong as the promise. This standard works the chain in order.

## The ten blocks

| Block | What it settles |
|---|---|
| 1. Buyer and stage | Buying situation, awareness stage, the visitor's own words, one goal; a gate on the message before any design |
| 2. First screen | Benefit or pain headline, a subheadline that makes it tangible, primary action with a risk-reducing line, proof and a real product visual; the five-second test |
| 3. Proof ≥ promise | A pyramid from strong to detailed, proof next to each claim, precise numbers, real people |
| 4. Objections in order | Sections that answer the question of each point of the scroll; features as outcomes; FAQ from real objections |
| 5. Calls to action | Labels that say what happens, repeated about every one and a half sections, visually dominant |
| 6. Pricing | What the page sells, smart defaults, one axis of value, full price up front |
| 7. Signup | Minimum fields, reserve first and verify later, confirm the decision after signup |
| 8. Visual | Contrast with what the buyer sees every day, one point of attention, real images |
| 9. Speed | Any platform, grade A or good Core Web Vitals on a phone |
| 10. Measure | One conversion event and its funnel, the right traffic, one hypothesis at a time |
