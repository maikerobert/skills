# Skills

The standards I use every day to work with AI agents across my companies. Each folder is a skill in the `SKILL.md` format, which works in Claude (app, Claude Code and Cowork) and in ChatGPT/Codex.

[Leia em português](#em-português)

| Skill | What it solves |
|---|---|
| [Portable Code Standard](portable-code-standard/) | AI agents write code without putting their own name in classes, comments and commits, without tying the system to the auth, database or deploy of the platform that generated it, without secrets in the repository, and always in English. Ships a free automated check that runs before every commit. |
| [Web Launch Standard](web-launch-standard/) | The checklist I run before any page goes live: scope, technical SEO, images, social sharing, Google Analytics 4, accessibility, performance, forms, safe deploy and QA on the public URL. It first classifies the page as public or private, so a dashboard never gets an Open Graph image or a Search Console entry. Ships a free check for live pages. |
| [Humanizer PT-BR](humanizer-pt-br/) | Removes the signs of AI writing from Brazilian Portuguese text: 26 patterns, with absolute bans on em dashes, "não é X, é Y" and chopped sentences. Instructions in English, so anyone building for Brazil can use it. |

## Where they came from

Each one started as a real problem I kept running into while shipping product and content with AI agents.

The code came out signed with the tool's name, and when it was time to move the project to Git, the system depended on the tool's own authentication. Pages went live with a perfect local build and a broken social preview, missing analytics events or a dashboard indexed by Google. Portuguese text came out sounding like the same person every time, with the same em dash and the same punchline at the end of each paragraph.

I turned each fix into a written standard, with an automated check wherever a machine can do the checking.

## Install

The quickest way is to download the skill's `.zip` from the [Releases](../../releases) page.

- **Claude app and Claude.ai:** upload the `.zip` in the Skills area of the settings.
- **Claude Code:** copy the skill folder to `~/.claude/skills/` (personal use) or to `.claude/skills/` inside the project.
- **ChatGPT and Codex:** use "Create skill" on the Skills screen, or copy the folder to `~/.agents/skills/` (some versions use `~/.codex/skills/`).
- **Without installing anything:** the Portable Code Standard includes `references/agents-md-block.md`, ready to paste into a repository's `AGENTS.md`, so any agent that opens the project follows the same rules.

## Portable Code Standard in one minute

Inside your repository:

```bash
mkdir -p scripts
cp path/to/portable-code-standard/scripts/*.sh scripts/
bash scripts/install-hooks.sh                 # installs the pre-commit and commit-msg hooks
bash scripts/check-portability.sh --all       # checks the whole repository
```

From then on, a commit with `ManusAuthProvider`, a "Generated by ChatGPT" comment, an API key in the code or a versioned `.env` is blocked before it leaves your machine. Words like "manuscript" or "cursor" pass normally.

## Web Launch Standard in one minute

```bash
python3 web-launch-standard/scripts/check-page.py https://your-site.com/
python3 web-launch-standard/scripts/check-page.py https://app.your-site.com/ --private
```

It checks the live page for status, HTTPS, metadata, canonical, headings, images, structured data, Open Graph and X cards, icons, analytics installation, `robots.txt` and `sitemap.xml`. On private pages it requires `noindex` instead.

## Em português

Os padrões que uso no dia a dia para trabalhar com agentes de inteligência artificial nos meus negócios. Cada pasta é uma skill no formato `SKILL.md`, que funciona no Claude e no ChatGPT/Codex. As instruções estão em inglês para que qualquer time no mundo possa usar.

- **Portable Code Standard:** a IA escreve código sem colocar o nome dela em classes, comentários e commits, sem amarrar o sistema à autenticação, ao banco ou ao deploy da plataforma que o gerou, sem segredos no repositório e sempre em inglês. Traz uma verificação automática e gratuita que roda antes de cada commit.
- **Web Launch Standard:** o checklist que eu rodo antes de colocar qualquer página no ar, com escopo, SEO técnico, imagens, compartilhamento, Google Analytics 4, acessibilidade, performance, formulários, deploy seguro e QA na URL pública. Ele começa perguntando se a página é pública ou privada, porque um dashboard não precisa de imagem de compartilhamento nem de Search Console.
- **Humanizer PT-BR:** tira a cara de IA de textos em português, com 26 padrões e vetos absolutos a travessão, a "não é X, é Y" e à frase picotada. Parte da skill open source humanizer, de Siqi Chen, com crédito e aviso de licença preservados.

Cada uma nasceu de um problema real que encontrei construindo produto e conteúdo com agentes, e virou um padrão escrito, com verificação automática onde a máquina consegue checar.

Para instalar, baixe o `.zip` na página de [Releases](../../releases) e envie na área de Skills do Claude ou do ChatGPT. Se usar em algum projeto seu, me conta. Vamos juntos.
