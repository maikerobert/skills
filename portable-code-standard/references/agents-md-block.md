## Portable Code Standard

Applies to any AI agent that creates, reviews or commits code in this repository.

1. **Neutral authorship.** No AI or AI tool names in classes, functions, variables, files, folders, packages, branches, logs, comments or commit messages. No "generated by AI" comments and no AI `Co-authored-by` trailer. Names come from the business domain.
2. **Platform independence.** Authentication, database, storage, email, payments and hosting use the provider defined by the project, never the AI tool's embedded service. Every external service sits behind a project-owned interface. Database schema in versioned migrations. Configuration through environment variables, documented in `.env.example`. The README explains how to run the project locally.
3. **Secrets stay out of the code.** No keys, tokens or passwords in the code or in the history. `.env` in `.gitignore`. Found a secret: stop, warn and recommend revoking it.
4. **English in the code.** Identifiers, files, branches, database tables and columns, comments and commit messages in English. End-user text follows the product's language.
5. **Clean repository.** No AI tool files, dead code or leftover debugging. Each commit does one thing and says what it did.
6. **Automated checks.** Run `bash scripts/check-portability.sh` before committing. Install the hooks with `bash scripts/install-hooks.sh`.
